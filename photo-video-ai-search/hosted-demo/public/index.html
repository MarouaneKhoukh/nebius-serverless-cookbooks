    BRING YOUR OWN ENDPOINT

    Connect photo search

    First, connect Qwen3-VL to make your collection searchable. When you choose Create an image, we’ll connect FLUX and guide you to review and approve the prompt.

    Where do I find these?

    Open your existing Endpoint’s Overview in the Nebius console. Under Network, copy the public URL for port 8000.

    Use the Endpoint auth token you chose and saved when creating it. For an existing Endpoint, open View code and copy the value after --token in its CLI example. You only need the token; do not run the create command again. The Endpoint must already be running. This is not your Nebius account API key.

    Checking photo search…

    Tokens stay in this tab’s memory and are never saved in browser storage or placed in a URL. The hosted app uses an HTTPS proxy; a local demo uses the proxy on your own machine.

    If FLUX runs on a separate Endpoint, use its auth token. Find the saved token or open View code and copy only the value after --token. Do not run the create command again.
