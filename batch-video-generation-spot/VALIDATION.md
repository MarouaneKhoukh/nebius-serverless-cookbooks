# Test results

Tested on 9 November 2026 in `eu-north1`.

| Component | Configuration |
| --- | --- |
| Deployment | Token-authenticated Serverless AI Endpoint, preemptible, following the market price |
| Image | `vllm/vllm-omni:v0.24.0` |
| Model | `Wan-AI/Wan2.1-T2V-1.3B-Diffusers` |
| GPU | One H100, `gpu-h100-sxm` / `1gpu-16vcpu-200gb` |
| Container disk | 500 GiB |
| Input | Three bundled prompts, seeds 42–44 |
| Generation | 832×480, 17 frames, 16 fps, 20 steps, `flow_shift=3.0`, `boundary_ratio=0.0` |

## Generation and resume checks

The three prompts produced three MP4s. FFmpeg decoded every file: each contained 17 frames and had a duration of 1.0625 seconds. The [clips and gallery](docs/sample-results/) are included with their prompts, settings and file hashes.

The client first generated one clip using `--limit 1`. A second run reused it and generated the remaining two. A third run reported **Generated 0; reused 3** and submitted no new generation requests.

The test covered continuation across client runs. Provider-initiated preemption, mid-clip recovery and automatic Endpoint restart were not tested. Completed clips are reusable; lost unfinished requests require explicit resubmission with `--retry-lost`.

These short previews establish that this configuration generated playable clips. They are not a video-quality benchmark.

## Local checks

```bash
python3 -m unittest discover -s tests -v
python3 src/generate.py --check-input
```

All 21 checks passed with Python 3.14 and local FFmpeg/ffprobe. Coverage includes input validation, request/poll/download handling, partial batches, completed-result reuse, changed inputs, corrupt or truncated files, lost requests and Endpoint-helper behavior.

The local tests use generated test patterns. The MP4s in `docs/sample-results/` were generated by Wan on the Endpoint.

## Price comparison

The quoted H100 rates were $0.79/hour for preemptible compute and $4.50/hour for regular compute. Adding $0.048611/hour for the 500 GiB disk gave rounded totals of **$0.84/hour preemptible** and **$4.55/hour regular**, before tax.

These are configuration quotes from the test date, not measured costs per clip. Rates can change, and startup, model loading and idle time are billable.

## Final resource state

The Endpoint was verified `STOPPED` after generation and the completed-result rerun. Downloaded clips and reports were retained locally.
