# Saved video batch

These eight MP4s were generated on Nebius Serverless AI on November 9, 2026 using **Wan2.1-T2V-1.3B** on a preemptible H100. Open `index.html` after cloning the repository to play them together, or download individual files. JPEG posters are frames extracted from those same clips.

Every clip has 49 frames at 16 fps, 832×480 resolution and 20 inference steps. `clips.csv` joins outputs to their prompts, seeds, source categories and hashes. `summary.json` and the per-clip JSON files record settings and decoded properties.

Inputs are eight published VBench prompts, one per content category. [Source attribution](DATA_SOURCE.md), [selection](input.source.json) and the unchanged [Apache 2.0 source license](DATA_LICENSE) are included. This subset does not produce a VBench score.

The MP4s have no branded overlay. You can reuse the files and manifests in your own application; the Nebius-branded gallery is a preview of the saved batch. See [validation](../../VALIDATION.md) for the measured run and its limits.
